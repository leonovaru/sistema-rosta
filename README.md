# Система роста

Личный веб-инструмент для управления восемью направлениями дохода: цели, задачи, ежедневный и недельный план, календарь день/неделя/месяц для встреч/дороги/хобби/сна с ежедневными и еженедельными повторениями, плановым и фактическим временем, поступления, расходы, долги, погашения и повторяющиеся обязательные платежи с расчётом денежного остатка. Рабочая структура включает клиентов, проекты с ИИ-декомпозицией на задачи и отдельные личные области с вложенными задачами и шаблонами повторяющихся дел (ежедневно, еженедельно, ежемесячно), которые создают отдельные задачи на ближайшие 30 дней.

## Технологии
- Cloudflare Pages (статический интерфейс + Pages Functions)
- Cloudflare D1 (данные)
- Web Crypto API (хеширование паролей)
- Vanilla JavaScript, без сборщика

## Локальная разработка
1. Установить Node.js и Wrangler: `npm install`
2. Создать D1: `npx wrangler d1 create sistema-rosta-db`
3. Вставить выведенный database_id в `wrangler.toml`.
4. Применить схему: `npm run db:migrate:local`
5. Запустить: `npm run dev`

## Развёртывание
Настроить D1 binding с именем `DB` в Cloudflare Pages и применить миграцию к production-базе. Подробные шаги — в `docs/DEPLOY.md`.

## Безопасность
По умолчанию разрешено создать только первый аккаунт; после его создания регистрация закрывается. Не включать `ALLOW_REGISTRATION=true`, пока не подготовлен контролируемый бета-доступ. Не коммитить секреты и реальные данные пользователей. Перед публичным запуском необходимы тестирование, ограничение частоты запросов, подтверждение email, восстановление пароля, CSRF-защита, политика конфиденциальности и проверка API.

Текущая версия — ранний MVP, не готовый публичный SaaS.
