## Этап 5 — личная финансовая система и жизненные цели
- [ ] Единый финансовый контур: все доходы, расходы, переводы, накопления, инвестиции, долговые обязательства и фактические выплаты; категории и привязка операций к направлениям, клиентам, проектам и личной жизни.
- [ ] Разделение факта, плановых операций и прогнозов: план не должен автоматически становиться фактической операцией.
- [x] Базовый прогноз переменных расходов на следующий календарный месяц по категориям на основе трёх последних завершённых месяцев; категории без истории не прогнозируются.\n- [x] Базовый бюджет: план/факт по месяцам и категориям, лимиты и анализ повторяющихся превышений; расчёт доступного остатка для целей ещё требует расширения.\n- [ ] Улучшить прогноз: сезонность, тренд, пользовательская корректировка и сравнение прогноза с фактом (базовый учёт нерегулярных и разовых трат уже добавлен).
- [ ] Долгосрочная финансовая модель по месяцам и годам: сценарии доходов и расходов, темпы роста, инвестиционная доля, накопления, капитал и предполагаемый пассивный доход.
- [ ] Настраиваемые допущения модели и сценарии (осторожный, базовый, амбициозный); отображение формул, источников и влияния изменения параметров.
- [ ] Полное автоматическое распределение доступного бюджета между обязательными расходами, долгами, резервом, инвестициями и целями по заданным приоритетам (текущие корзины распределяют поступления, но не заменяют эту модель).
- [x] Базовые финансовые цели с суммой, сроком, приоритетом, накопленной суммой, регулярным взносом и статусом; прогнозная дата и расширенное управление этапами требуют развития.
- [x] Предварительная оценка достижимости цели по 90-дневной истории доходов, расходов, выплат по долгам и взносов в другие активные цели; осторожный коэффициент 70%.\n- [ ] Расширенная проверка достижимости: нерегулярные/плановые потоки, обязательства будущих месяцев, конфликтующие цели и предложения альтернативных сроков.
- [x] Базовый раздел «Мечты»: список желаний с описанием, изображениями/ссылками, примерной стоимостью, желаемым сроком, категорией и приоритетом.
- [x] Преобразование мечты в финансовую цель с подтверждением пользователя и сохранением суммы, срока, приоритета и ежемесячного взноса.\n- [ ] Автоматическое создание этапов и задач из финансовой цели; проверка достижимости по общему бюджету.
- [ ] Панель жизненного капитала: прогресс по целям, резерв, долги, накопления, инвестиции и прогноз чистого капитала.

## Этап 8 — сон и восстановление
- [x] Ручные отметки отхода ко сну, засыпания и пробуждения с редактированием истории.
- [x] Учёт часового пояса каждой отметки, включая поездки и неоднозначные переходы летнего/зимнего времени.
- [x] Статистика за 7 и 30 дней: средняя продолжительность, среднее время засыпания/пробуждения, вариативность и количество записей.
- [x] График продолжительности сна за 30 календарных дней; пропуски и неполные ночи не считаются нулём.
- [x] Настраиваемая личная цель продолжительности сна и сравнение фактической средней с целью.
- [ ] Применить миграции сна и цели сна к D1 после проверки истории миграций.
- [ ] Настроить и развернуть Web Push Worker, VAPID и cron; проверить уведомление на реальном телефоне.
- [x] Показывать завершённые интервалы сна в календаре как виртуальные события; конвертировать время по часовым поясам отметок и настройке календаря, не создавать дубликат при пересечении с ручным событием; учитывать сон как занятость при дневном планировании. Миграции сна должны быть применены до запуска.

- [ ] Импорт из Apple Health / Health Connect через отдельный совместимый мост; обычная веб-страница не имеет прямого доступа.
